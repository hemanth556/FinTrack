# FinTrack – Personal Finance Management

FinTrack is a modern, responsive SaaS landing page designed for a personal finance management platform. It helps users understand how they can track expenses, manage budgets, monitor savings, and make smarter financial decisions.

# Features

- **Modern Landing Page:** Clean and professional SaaS design.
- **Responsive Navigation:** Mobile-friendly navigation with smooth section scrolling.
- **Hero Section:** Dashboard preview with financial statistics.
- **Expense Tracking:** Introduces smart expense management.
- **Financial Insights:** Highlights spending analytics and reports.
- **Budget Management:** Helps users understand budgeting features.
- **How It Works:** Explains the platform through three simple steps.
- **Pricing Plans:** Free and Pro plans with monthly/yearly billing toggle.
- **Contact Form:** Input validation and submission success message.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

##  Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/hemanth556/FinTrack.git
```

### 2. Navigate to the project directory

```bash
cd FinTrack
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Visit:

```text
http://localhost:5173
```

##  Responsive Design

FinTrack is designed to work across different screen sizes:

- Desktop
- Laptop
- Tablet

##  Design Choices

- Used an emerald green and white color palette to create a clean financial technology aesthetic.
- Used a modern typography hierarchy with consistent spacing.
- Designed reusable React components for better code organization.
- Used Tailwind CSS for responsive layouts and styling.
- Added interactive elements to improve usability.
- Focused on simplicity, readability, and visual consistency.

## Functional Interactions

- Navigation links scroll to relevant website sections.
- Mobile navigation menu opens and closes.
- Pricing toggle switches between monthly and yearly billing.
- Contact form validates user inputs.
- Successful form submission displays a confirmation message.

**Note:** This is a frontend-only project. No backend, database, authentication, or payment integration is included. Contact form submissions are not stored or sent to a server.
